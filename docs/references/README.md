# Dokumen Referensi Proyek

Folder ini berisi referensi proses dan struktur yang harus dipertahankan selama pengembangan frontend:

- `BPMN-semester-3.png`: alur proses bisnis utama.
- `Use-Case-semester-3.png`: aktor dan use case sistem.
- `ERD-semester-3.png`: relasi entitas data.
- `schema-semester-3.sql` pada folder `docs`: draft skema relasional yang perlu diselaraskan backend dengan ERD.

Desain UI baru tidak menggunakan render Figma lama sebagai acuan visual. Nama aplikasi, identitas logo/warna, scope, aktor, proses dan model data tetap mengikuti dokumen proyek semester 3.
